Privacy Policy

Last updated: October 13, 2026

This policy explains what the Discord bot nyan, run by the nyan developer (GitHub: pika-botinok223), stores and processes. The bot’s source code is public at github.com/pika-botinok223/nyan, so you can check everything below.

Short version: nyan stores server settings and economy data (IDs, balances, timestamps, shop items). It reads messages only to check them for scams and spam, and does not save message content in its database. We do not sell or share your data.

1. What nyan stores

nyan keeps a SQLite database file on the machine where the bot runs. It contains only the following, grouped by table. Each row is tied to a Discord server ID (a “guild ID”).

TableWhat it holds
sec_settingsServer ID; the mod-log channel ID and honeypot channel ID; on/off switches for anti-raid, anti-scam, honeypot and spam detection; thresholds, time windows, punishment types and durations (for example 8 joins in 10 seconds, kick or timeout, timeout minutes, lockdown minutes, minimum account age in days).
sec_domainsServer ID and the domain names that server’s admins added to the scam block list or allow list.
eco_configServer ID, the custom currency name and currency emoji.
eco_usersServer ID and user ID; that user’s balance in that server; the time of their last /daily claim and their daily streak; the time of their last /work.
eco_shopServer ID and the shop items admins created: item name, price, and the ID of the role it grants (if any).
eco_inventoryServer ID, user ID, the names of shop items that user owns and how many.

nyan does not store usernames, nicknames, avatars, email addresses, IP addresses, message content, attachments, or voice data in its database. The user IDs above are Discord’s numeric IDs, and only users who use the economy commands (for example /daily, /work, /pay, gambling, shop) get a row. Receiving or sending coins can also create a row for the other member.

2. What nyan processes but does not store

To protect servers, nyan needs Discord’s Message Content and Server Members intents. This means it receives messages and member joins in servers where it is added. It uses them like this:

  • Message content is scanned in memory (including edited messages) to find phishing links, lookalike domains, fake giveaways and masked links. Nothing is written to the database; the text is discarded once the check is done.
  • Recent messages for duplicate-spam detection are held in memory only: for each recent poster nyan keeps a short window (by default 30 seconds, at most 20 messages per user) of the lower-cased text plus the channel ID and message ID, and drops it after a few minutes of inactivity. This is lost when the bot restarts.
  • Join timestamps (member ID and time of joining, a bounded number per server) are held in memory only to detect join floods. Whether a server is in lockdown is also kept in memory only.
  • Account creation date of a joining member is read, if the server enabled new-account flagging, to compare against the configured minimum age. It is not saved.
  • Messages from bots and from members the bot never punishes (owners, administrators, moderators) are not acted on.

3. Moderation logs live in Discord

When nyan acts (deletes a scam message, times out, kicks or bans someone, starts a lockdown, flags a new account), it can post a report to the mod-log channel the server chose with /security modlog. That report may include the member’s mention and user ID, the channel, the reason, the action taken, and an excerpt of the offending message (up to 500 characters, with links defanged so they can’t be clicked). Moderation actions also appear in the server’s Discord audit log with a reason.

These logs are stored by Discord, inside that server, and are controlled by the server’s staff (who can delete them or change channel permissions). nyan does not keep its own copy.

4. Operational logs

The bot writes ordinary technical logs on the machine it runs on (for example errors, startup messages, and short lines such as “raid action on user ID X in server ID Y”). These may contain server and user IDs but not message content. They are used only to run and debug the bot.

5. How the data is used

Only to provide nyan’s features: moderation and protection, the economy and shop, and the commands you ask it to run. We do not use it for advertising, profiling or analytics, and nyan has no trackers.

6. Sharing

We do not sell, rent or share your data. The only third party involved is Discord itself, which delivers messages and events to the bot and receives the bot’s actions and replies; Discord’s own Privacy Policy applies to that. This website is static, uses no scripts or cookies and has no analytics. It is hosted on GitHub Pages, which may keep its own server logs.

7. Retention and deletion

Stored data is kept until it is deleted. Removing nyan from a server stops all processing for that server, but its stored settings and economy rows are not automatically erased, so they are still there if you re-add the bot. Admins can remove some data themselves (for example shop items with /shop remove, and domain entries with /antiscam remove).

To request deletion of a server’s data, or of your own user data, open an issue at github.com/pika-botinok223/nyan/issues stating the server ID (and/or your user ID). Issues are public, so don’t include anything else private. We may ask you to show that you have the authority to ask (for example, being an admin of that server). We will delete the matching rows from the database. In-memory data disappears on its own when the bot restarts. Messages in a server’s mod-log channel are in Discord and have to be deleted by that server’s staff.

8. Security

We limit access to the database file and the bot token and try to follow reasonable practice, but no system is perfectly secure and we cannot guarantee absolute security.

9. Children

nyan is not meant for children under the minimum age Discord requires in your country (13 in most places). Using Discord, and therefore nyan, is only allowed at or above that age. We do not knowingly collect data from anyone below it; if you think we have, ask for deletion as described above.

10. Changes to this policy

We may update this policy when the bot changes. The “Last updated” date at the top shows the latest version, and the full history is in the public GitHub repository. If you keep using nyan after a change, you accept the updated policy.

11. Contact

Questions or requests: open an issue on GitHub. See also the Terms of Service.
