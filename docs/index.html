nyan 🐾

A cat-themed Discord bot that keeps your server safe from raids, scams and spambots, and gives your members a little economy and some toys to play with.

  • Anti-raid: spots join floods, locks the server down for a while and can flag brand-new accounts.
  • Anti-scam: catches phishing and lookalike links, fake “free nitro” posts and masked links, with your own block and allow lists.
  • Spambot trap: a “do not post here” honeypot channel plus a cross-channel duplicate-spam detector.
  • Economy and fun: per-server currency, daily rewards, a role shop, and toys like /8ball, /rps and /hug.
Add nyan to your server View on GitHub

Run /help in Discord to see every command. The invite asks only for the permissions nyan needs to moderate; put nyan’s role above the roles it should moderate.
